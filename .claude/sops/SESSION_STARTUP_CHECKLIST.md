# SESSION STARTUP CHECKLIST
**Effective:** 2026-04-14 onwards
**Status:** MANDATORY — Run at session start, every time

---

## BEFORE ACCEPTING ANY TASK

### ✅ Step 1: Memory Load (2 minutes)
- [ ] Read MEMORY.md → understand current context
- [ ] Search MEMORY.md index for task-related keywords
- [ ] Read any relevant memory files discovered
- [ ] Note any locked-in decisions or corrections from prior sessions
- [ ] Confirm: Do I understand the current state?

**If memory is unclear:** Ask user for context before proceeding.

---

### ✅ Step 2: Protocol Confirmation (1 minute)
- [ ] Read CLAUDE.md — project instructions
- [ ] Confirm current focus (what are we working on?)
- [ ] Check open issues list
- [ ] Read any relevant SOPs from skills/ directory
- [ ] Confirm: Do I know what I'm building?

**If unclear:** Ask user to clarify scope before proceeding.

---

### ✅ Step 3: Execution Discipline Check (1 minute)
- [ ] Confirm Execution Discipline Protocol is loaded and active
- [ ] Verify: I will NOT guess, embellish, or fabricate
- [ ] Verify: I will check for existing patterns/templates first
- [ ] Verify: I will use verified sources only
- [ ] Verify: I will run 8-item self-QA before sending anything
- [ ] Confirm: Discipline is my priority, not speed

**If unsure about any rule:** Review execution_discipline_protocol.md again.

---

### ✅ Step 4: Task Type Identification (2 minutes)
**For every task user gives:**

- [ ] Does this match an existing workflow? (check CLAUDE.md, SESSIONS.md)
- [ ] Does this match an existing SOP? (check skills/)
- [ ] Does this match a previously approved template? (check scripts/, prior emails)
- [ ] Does this match previously approved output? (check MEMORY.md references)

**Result:**
- **YES to any:** This is recurring work → apply full Execution Discipline Protocol
- **NO to all:** This is genuinely new work (rare) → still apply protocol, but expect to clarify more

---

## BEFORE STARTING WORK

### ✅ Step 5: Verify Source Material (2-3 minutes)
- [ ] User has provided all required data (or I know where to get it)
- [ ] I have access to relevant databases (Markaz, Teams, Gmail, etc.)
- [ ] I have located the reference template/SOP if applicable
- [ ] I understand the format/tone/structure expected

**If missing:** Ask user for clarification BEFORE starting work.

---

### ✅ Step 6: Search for Prior Work (3-5 minutes)
**Before creating anything new:**

1. Search MEMORY.md for similar completed work
2. Search SESSIONS.md for prior task logs
3. Search scripts/ for reference implementations
4. Search CLAUDE.md → Quick Reference for templates
5. Search skills/ for relevant SOPs
6. Ask: "If this file/email/report exists, where would it be?"

**Only after thorough search:** Conclude it doesn't exist and proceed to create.

---

## LOCK-IN CHECK

### ✅ Step 7: Confirm Any Prior Corrections (1 minute)
**For recurring work, VERIFY locked-in standards:**

- [ ] Rejection emails: format confirmed (no asterisks? blue bold? v8 design?)
- [ ] Attendance reports: 10-section structure confirmed
- [ ] Values emails: tone confirmed (warm? specific? transcript evidence?)
- [ ] All candidate-facing emails: jargon-free? no internal names?
- [ ] Any other format corrections from prior sessions locked in?

**Check against:** MEMORY.md for any "Feedback" type memories about format/tone.

---

## CHECKPOINT

### ⚠️ Before Proceeding — Final Check

**Can you answer YES to all of these:**
- [ ] I have read MEMORY.md and understand current state
- [ ] I understand the task and its scope
- [ ] I know where the reference/template is (or confirmed it doesn't exist)
- [ ] I understand the locked-in format/tone/structure
- [ ] I have verified source material is available
- [ ] Execution Discipline Protocol is active in my thinking
- [ ] I am NOT going to guess, assume, or fabricate

**If any NO:** Stop. Ask user for clarification. Do not proceed until all are YES.

## SESSION READY

**Once all checks pass:**

1. You are cleared to proceed
2. Apply Execution Discipline Protocol while working
3. Before sending ANY output: run 8-item self-QA checklist (from protocol)
4. After completing task: save learnings to MEMORY.md (close the loop)

**Session is active and disciplined.**

---

## QUICK REFERENCE: The 8-Item Self-QA Checklist
(Run BEFORE sending any work)

- [ ] **File names and existence** — Verified actual file names, checked they exist or need creating
- [ ] **Formatting** — Matches approved format exactly (logo, headers, fonts, spacing, color codes, section structure)
- [ ] **Tone** — Matches approved tone (warm vs. direct, jargon-free, "we" voice, etc.)
- [ ] **Duplication** — No repeated sections, greetings, headings, or content
- [ ] **Jargon removal** — No internal terminology ("GWC", "Zero In Call", process names, reviewer names)
- [ ] **Encoding/spelling artifacts** — No em dashes showing as garbage, no weird characters, no typos
- [ ] **Consistency with approved examples** — Compared to reference work, structure/tone/format matches
- [ ] **Factual grounding** — Every claim tied to source material (user data, Markaz DB, approved template, prior decision)

**Only send work after ALL 8 checks pass.**
