# Sub-skill: NDAs (Permanent Employee & Fellow)

Sub-skill of [Skill 07 — Contract Drafting](SKILL.md). Read the master workflow + [TEMPLATE_MAP.md](TEMPLATE_MAP.md) first.

---

## The two NDA types — never swapped

| NDA | Master | Who signs it |
|---|---|---|
| **Permanent Employee NDA** ("Full-time - Permanent", Orenda) | `Contracts\Promotion\Template - NDA Full Time Permanent Employee.docx` | Permanent employees of **all four entities — OPL, OWT, NIETE, and Inc.** (one Orenda master covers all; Ayesha 2026-08-12) |
| **Fellow NDA** ("Part Time - Fellowship", Orenda) | `Contracts\Fellow\Template - NDA Fellow Employee.docx` | Fellows / interns — **never** the permanent NDA |

## Fill fields (yellow-highlighted — and NOTHING more)

Both NDAs take exactly:
- **Full legal name** (opening clause + printed-name line)
- **Joining date** (effective date)
- **Current date** (employer signature line)

**Hard rule:** never insert CNIC, designation, dates, or any other information into an NDA the template doesn't ask for. Preserve every existing field, article, and clause untouched.

## Validation checklist (before showing Ayesha)

- [ ] Correct full legal name (spelling verified) on both fill points
- [ ] Correct NDA type for the person (Permanent vs Fellow)
- [ ] Correct joining date + current date
- [ ] No details belonging to another person (full-document scan)
- [ ] No unresolved placeholders (EMPLOYEE NAME / FELLOW NAME / JOINING DATE / CURRENT DATE) and no remaining yellow highlighting
- [ ] Standard NDA wording not modified in any way

## Procedure

1. Pick the type from the engagement (permanent → Permanent NDA; Fellow → Fellow NDA; unclear → ask Ayesha, never guess).
2. Copy master → `output/contracts/<Full Name>/NDA - <Full Name> - <Permanent|Fellow>.docx`. Never overwrite the master.
3. Fill the three fields; clear highlighting on filled runs.
4. Run the checklist above.
5. **The NDA ships with its contract** — a package missing either document is not ready ([SKILL.md](SKILL.md) Step 7).
