## NIETE Project-Based — fill fields (yellow-highlighted)

Header: Current date, CNIC, Name · Effective date of joining · Mr./Mrs. NAME + CNIC (parties clause) · **Term: start DATE, MONTH, YEAR → end DATE, MONTH, YEAR** · duration XYZ · Employer signatory name + designation · Acceptance: NAME + CNIC · **Direct Report to: xyz**.
**Fixed (never touch):** probation 13 weeks/3 months; unlimited trust-based leaves; in-house lunch clause; asset-responsibility clause; 30-day termination notice; no-permanency clause; deliverables-contingent salary disbursement clause.

## Required information (ask only what's missing)

Full legal name + salutation (Mr./Mrs. — always ask, never infer) · CNIC · designation + department + salary · **contract START date AND END date + duration — both mandatory; double-check them, this is the #1 validation point on fixed-term contracts** · Direct Report to · employer signatory name + designation · **JD (ask Ayesha every time)** → under **Annexure-A inside the same document**.

## Procedure

1. Copy master → `output/contracts/<Full Name>/Contract - <Full Name> - NIETE Project-Based.docx`. Never overwrite the master.
2. Fill ONLY yellow fields; clear highlighting on filled runs.
3. JD under Annexure-A.
4. Run the contract validation checklist in [SKILL.md](SKILL.md) — explicit second pass on start date, end date, duration.
5. Package with the correct NDA ([ndas.md](ndas.md)).
6. Joining email: ⏳ template pending — flag until shared.
7. Show Ayesha the complete package. No send without explicit approval.
