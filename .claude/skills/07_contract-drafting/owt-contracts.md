## ⚠️ Fill-field exception (Ayesha-approved 2026-08-12)

Both OWT templates carry **no yellow highlighting**. The official fill fields are the **`XYZ` placeholders and blank-after-colon header spots** (Date:, CNIC:, Name:). Everything else is fixed legal text.

## OWT Full-Time — fill fields

Header: Date, CNIC, Name · Body: Mr./Ms. XYZ, position XYZ, **XYZ Department**, effect-from XYZ · Compensation: Gross Salary PKR XYZ/month (inclusive of tax) · Signature block: **HOD Name + Designation** · Acceptance: XYZ + CNIC XYZ.
**Fixed (never touch):** probation 13 weeks/3 months; "required to work from the office" (Role Assignment); **acceptance validity 1 working day**; termination clauses; OWT letterhead (2nd Floor, Time Square Plaza, I-10 Markaz).

## Required information (ask only what's missing)

Full legal name + salutation (always ask, never infer) · CNIC · designation + department · effect-from date · gross salary PKR/month · HOD name + designation · **JD (ask Ayesha every time)** → under **Annexure-A inside the same document**.

## Procedure

1. Copy master → `output/contracts/<Full Name>/Contract - <Full Name> - OWT Full-Time.docx`. Never overwrite the master.
2. Fill ONLY the XYZ/blank fill spots; leave every fixed clause untouched.
3. JD under Annexure-A.
4. Run the contract validation checklist in [SKILL.md](SKILL.md) — placeholder scan is critical here since there is no highlighting to catch a missed field.
5. Package with the correct NDA ([ndas.md](ndas.md)).
6. Joining email: ⏳ template pending — flag until shared.
7. Show Ayesha the complete package. No send without explicit approval.
