## Overview
Track case study submissions, assess quality, identify missing parts, keep Ayesha proactively informed.

## The 8 Steps

1. **Check Markaz** — Candidate Communication section, verify case study sent
2. **Check submission status** — Text submission or file upload?
3. **Check Gmail** — Search for submission emails ("New Case Study Submission")
4. **Download submission** — Retrieve file(s)
5. **Read original assignment** — Know what was asked before evaluating
6. **Read submission thoroughly** — Full read, no skipping sections
7. **Evaluate quality + completeness** — Assess answers, identify gaps
8. **Flag AI or weak effort** — Note AI indicators, shallow thinking, low effort

## Critical Rules

- **Check BOTH sources** — Markaz AND Gmail. Never one only.
- **Read original first** — Can't evaluate answer without knowing question.
- **Full read, one-by-one** — Each submission read completely, independently.
- **Be specific on gaps** — Name exactly what's missing, not just "incomplete".
- **Automation is mandatory** — Auto-flag incomplete to Ayesha same day.
- **Weekly proactive reporting** — Don't wait for ask. Report: submitted, overdue, follow-up needed.

## Automation Requirement

As soon as candidate submits:
- Coco reads it
- Identifies missing parts
- Emails Ayesha ONLY if incomplete (template: "[Candidate Name] Case Study — Missing Parts: [list]")
- No delays, same day/next morning

## Weekly Reporting

Every 7 days, proactively send Ayesha:
- **Who submitted this week** (names, App IDs, roles, quality flags)
- **Who is overdue** (names, days past 48hr deadline)
- **Who needs follow-up** (incomplete submissions, AI flags, etc.)

Format: concise summary email, no wait for ask.

## Common Mistakes

1. Only check Markaz (miss email submissions)
2. Only check Gmail (miss form submissions)
3. Read assignment after evaluating answer
4. Skip sections of submission
5. Miss the automation step (don't email Ayesha immediately)
6. No weekly reporting (reactive not proactive)
7. Vague about gaps ("incomplete" instead of "missing Exercise 3")
8. Batch multiple candidates (blend impressions, miss details)
9. Don't flag AI/weak effort (no honest assessment)
10. Wrong file format not caught
