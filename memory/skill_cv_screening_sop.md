## Overview
CV Screening is a **7-step manual review process** that evaluates every candidate profile against the JD with full accuracy. No skipping profiles. No shortcuts on reading. Minimum CV reading capacity: 14,000–15,000 characters per resume.

## The 7 Steps

**Step 1:** Read JD in detail (requirements, exp, salary, must-haves, nice-to-haves)
**Step 2:** Review EVERY profile manually (no algorithmic filtering)
**Step 3:** Download and read resume fully (no truncation, 14k-15k char threshold)
**Step 4:** Read candidate questions (salary, city, relocation, custom fields)
**Step 5:** Assess experience fit (state BOTH total AND relevant exp separately)
**Step 6:** Competitor experience noted but not prioritized (skills+exp = top criteria)
**Step 7:** Maintain email format (stat boxes, hyperlinked names, description+gaps, tables)

## Non-Negotiable Rules

- Read EVERY profile manually. No exceptions.
- State both total AND relevant experience explicitly.
- Do not assume data. If not in CV, state "Not mentioned."
- Candidate questions are mandatory: expected salary, city, relocation willingness.
- Skills + Experience = TOP criteria. Rank by JD match + relevant exp fit.
- No filtering based on demographics (name, gender, nationality, age, origin).
- Over-budget candidates are flagged, not excluded.
- Report format is exact (see email structure below).
- All candidate names must be hyperlinked to Google Drive CVs.
- Always ask for approval before sending. PILOT → approval → LIVE.

## Email Format (Mandatory)

**Header Block:** Dark navy bg, uppercase header "People & Culture · Initial Screening Report", job title, "Job [X] · Taleemabad"

**Stat Boxes:** 4 colored boxes (red, blue, yellow, gray) showing Total / Shortlisted / Maybe / No Hire

**Key Observation:** Blue header + 2-3 sentence insight on candidate pool patterns

**Shortlisted Candidates:**
```
1. [Name — hyperlinked]  |  [RANKING]  |  [Score %]
App ID: ####  |  Total exp: ~X yrs  |  Relevant exp: ~X yrs  |  Expected Salary: [amount]  |  City: [location]  |  Relocate: [Y/N]  |  DB status: [status]
[3–4 sentence description] [Gap paragraph] [DB warning if needed]
```

**Maybe Section:** Table (Candidate | Match % | Note)

**Special Flags:** PM experience or other flags if requested

**Footer:** "Taleemabad Talent Acquisition | hiring@taleemabad.com | [Date]"

## Common Mistakes

1. Skipping profiles — every one must be reviewed
2. Partial resume reading — read the entire resume
3. Assuming relevant exp — read actual job descriptions
4. Conflating total/relevant exp — always state both separately
5. Flagging CVs <14k chars as too long — threshold is 14–15k
6. Ranking by competitor signal alone — must align with JD
7. Missing candidate profile data (salary, city, relocation)
8. Wrong stat box counts — verify math before sending
9. Changing report format — match exactly
10. Not hyperlinking names — every name must be clickable
11. Sending without approval — always ask first
12. Missing gap paragraphs — every shortlisted candidate needs balanced view
