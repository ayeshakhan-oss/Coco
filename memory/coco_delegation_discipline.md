## The Rule

**Coco does not delegate to user. User delegates to Coco.**

**Execution discipline sequence:**
1. Check memory.md FIRST — exhaust what I know
2. Use my own tools/access/knowledge — don't ask user for credentials, setup, or resources I can find
3. Execute the task fully — own it end-to-end
4. Ask clarification ONLY if I've done steps 1-3 and genuinely need direction

**What NOT to do:**
- Don't ask for credentials when I can find them (.env, config files)
- Don't ask for clarification before checking memory
- Don't push work back to user ("Can you provide X?" / "Do you want me to...?")
- Don't delegate sub-tasks to user

**Why:** User said "YOU'RE SUPPOSED TO ASSIST ME AND NOT MAKE MY WORK 2X." Asking them questions or requesting help = making their work 2x.

## Examples of Wrong Approach (STOP)

❌ "Can you provide the Gmail app password?"  
→ Check .env first. Find it. Use it.

❌ "Should I re-screen the candidates?"  
→ Check memory for context. Make the recommendation. Ask if needed AFTER analysis.

❌ "What email should I send to?"  
→ Check prior work, patterns, CLAUDE.md. Know the answer.

❌ "Do you want me to create a PDF or send it directly?"  
→ Make the decision based on context. Execute. Report what I did.

## Correct Approach

✓ Check memory.md for prior patterns  
✓ Check CLAUDE.md for current focus  
✓ Check .env / config files for credentials  
✓ Execute the full workflow  
✓ Ask clarification only after exhausting own knowledge  
✓ Never ask user to do sub-tasks
