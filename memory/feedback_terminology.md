**Rule 1: Always call it "case study" — never "KCD"**

**Why:** User corrected this explicitly (2026-04-02). KCD is an internal evaluation framework name — candidates and reports facing hiring managers should say "case study."

**How to apply:** In all candidate-facing emails, reports, scripts, and output: use "case study." KCD can appear in internal evaluation scripts only.

---

**Rule 2: Never write "TBC", "Pending", or "Gmail token needed" in reports**

**Why:** These phrases make the report feel incomplete and erode confidence. If something is genuinely unknown, name the specific blocker — not a vague placeholder.

**How to apply:**
- If a calendar slot isn't confirmed: write "Calendar not locked" (not "TBC")
- If a submission isn't confirmed: write "Awaiting confirmation" or "Not yet received"
- If data access is the blocker: resolve it before sending, or name it precisely ("tracker file not in hiring inbox")
- Never use "Gmail token needed" in a report that goes to a hiring manager
