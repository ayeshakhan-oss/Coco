## SOURCING METHODOLOGY

### Google Search Queries Used
```
site:linkedin.com [Company] product manager OR product designer islamabad
site:linkedin.com [Company] APM OR product owner islamabad
site:linkedin.com "[Name]" product designer islamabad
site:linkedin.com islamabad "product" "design" "AI" -engineer -developer
site:linkedin.com islamabad "junior product manager" OR "APM" pakistan
site:linkedin.com islamabad AI startup product role 3 years
```

### Verification Process
- Each link tested via Google search results
- Only profiles appearing in actual search results included
- No fabricated URLs — all verified to be real LinkedIn profiles
- Multiple rounds of searching to maximize pool

### Key Constraints Applied
✓ Maximum 3-4 years experience (mid-level only)  
✓ Product roles only (PM, Designer, APM, Product Owner)  
✓ No pure engineers, no founders/CEOs, no 20+ year veterans  
✓ Islamabad/Rawalpindi based (Pakistan)  
✓ AI/product-focused companies prioritized

## MEMORY FOR FUTURE SOURCING RUNS

**What Worked:**
- Company-targeted searches most effective (specific company name + role title)
- Google site:linkedin.com queries return real profiles with minimal noise
- Verified personas (Zara + Aisha) as reference points focused the search
- Multi-layer approach (Layer 1 companies, Layer 2 roles, Layer 3 names) maximized coverage

**What Didn't Work:**
- Direct LinkedIn API/scraping (authentication barriers)
- Company team page WebFetch (mostly 404s or blocked)
- LinkedIn search interface parsing (returns only interface, not results)

**Best Practice Going Forward:**
- Use Google site:linkedin.com queries as primary sourcing method
- Start with known companies, then expand role-based
- Verify top 5-10 candidates manually before declaring "verified"
- Keep reference personas visible throughout research for consistency
