# Skill: Report Generation — Talent Acquisition

## Purpose
Generate a structured, professional candidate screening report for hiring managers.

## Prerequisites
- Candidate scoring complete (see [../02_Candidate_Evaluation/cv_screening.md](../02_Candidate_Evaluation/cv_screening.md))
- All candidates ranked by composite score
- Top recommendation identified

## Output File
Save to: `output/YYYY-MM-DD-[position-name]-screening-report.md`
Example: `output/2026-02-26-senior-engineer-screening-report.md`

## Non-Negotiable Rules

1. **Consistent format** — All screening reports must follow this template structure.

2. **Top recommendation always included** — Never omit the "Top Recommendation" section.

3. **Shortlist ranked by composite score** — Rank 1 is highest composite score. Never reorder arbitrarily.

4. **Over-budget section always present** — Flag strong matches that exceed budget separately.

5. **Top 10 profiles detailed** — Always include detailed profiles for the top 10 shortlisted candidates.

6. **Scoring criteria explicit** — Always state the weighting (JD Match 40%, Exp 30%, Skills 20%, Budget 10%).

7. **Screening methodology transparent** — Explain how candidates were screened and excluded.

8. **Next steps clear** — Always include actionable next steps for the hiring manager.
