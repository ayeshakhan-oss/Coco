## Email Setup Options

### Option A: Gmail API (Recommended)
Requirements: A Google account, Gmail API enabled in Google Cloud Console.

**Setup steps:**
1. Go to console.cloud.google.com
2. Create a new project or select existing
3. Enable the Gmail API
4. Create OAuth 2.0 credentials (Desktop app)
5. Download credentials.json and place in project root
6. Tell the agent: "Set up Gmail API sending using credentials.json"

### Option B: SMTP (Simpler, works with any email provider)
Requirements: SMTP host, port, username, password.

Common SMTP settings:
- Gmail: smtp.gmail.com, port 587
- Outlook/Office 365: smtp.office365.com, port 587
- Custom domain: ask your IT/email admin

Store credentials in .env file (NEVER in CLAUDE.md or memory.md):
```
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=yourname@taleemabad.com
EMAIL_PASSWORD=your_app_password
```

### Option C: SendGrid API (Best for production)
Requirements: SendGrid account + API key.
Best for reliable delivery tracking and bounced-email handling.

## Sending a Report

### Python Script (SMTP method)
```python
import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart
from email.mime.base import MIMEBase
from email import encoders
import os

def send_screening_report(report_path, position_name, recipients):
    msg = MIMEMultipart()
    msg['From'] = os.getenv('EMAIL_USER')
    msg['To'] = ', '.join(recipients)
    msg['Subject'] = f"Candidate Screening Report: {position_name}"

    body = f"""Dear Team,

Please find attached the automated candidate screening report for: {position_name}

This report includes:
- Ranked shortlist of top candidates
- Composite scores (JD match, experience, skills, budget)
- Top recommended candidate with justification
- Over-budget strong matches flagged separately

The report was generated by the Taleemabad Talent Acquisition Agent.

Best regards,
Taleemabad Talent Acquisition Agent
"""

    msg.attach(MIMEText(body, 'plain'))

    # Attach the report file
    with open(report_path, 'rb') as f:
        part = MIMEBase('application', 'octet-stream')
        part.set_payload(f.read())
        encoders.encode_base64(part)
        part.add_header('Content-Disposition', f'attachment; filename="{os.path.basename(report_path)}"')
        msg.attach(part)

    with smtplib.SMTP(os.getenv('EMAIL_HOST'), int(os.getenv('EMAIL_PORT'))) as server:
        server.starttls()
        server.login(os.getenv('EMAIL_USER'), os.getenv('EMAIL_PASSWORD'))
        server.send_message(msg)

    print(f"Report sent to: {', '.join(recipients)}")
```

## Safe_sendmail Bouncer (MANDATORY)

All emails sent through Coco **must** use the safe_sendmail() bouncer, never smtplib.sendmail() directly.

**Why:** The bouncer enforces:
- Audit logging (who sent what, when, to whom)
- Recipient verification (catches wrong email addresses)
- Attachment validation (ensures reports are ready)
- Failure handling (logs failures, retries intelligently)

**Usage:**
```python
from scripts.utils.safe_sendmail import safe_sendmail

safe_sendmail(
    to=hiring_manager_email,
    cc=['hiring@taleemabad.com', 'ayesha.khan@taleemabad.com'],
    subject=f"Candidate Screening Report: {position_name}",
    body=email_body_html,
    attachments=[report_path],
    context=f"screening_report_job_{job_id}"
)
```

**Parameters:**
- `to` — primary recipient (string)
- `cc` — carbon copy recipients (list)
- `subject` — email subject
- `body` — email body (plain text or HTML)
- `attachments` — list of file paths to attach
- `context` — audit log context (what this email is for)

## Non-Negotiable Rules

1. **Always use safe_sendmail** — Never call smtplib.sendmail() directly.

2. **Verify recipients before sending** — Confirm email addresses are correct.

3. **Ask for approval before sending** — Always PILOT mode first, then live.

4. **Audit log every send** — The bouncer logs automatically, but verify logging happens.

5. **Verify attachments** — Ensure report file exists and is readable before sending.

6. **Check recipients match position** — Hiring manager for this position, not wrong person.

7. **Use descriptive context** — Context in bouncer should explain what report is being sent.

## Common Mistakes

1. **Sending to wrong email** — Sending to wrong hiring manager. Verify recipients.

2. **Using smtplib directly** — Bypassing safe_sendmail bouncer. Always use bouncer.

3. **No CC on reports** — Forgetting to CC hiring@ and ayesha.khan@. Always include them.

4. **Sending without approval** — Sending live without Ayesha review. Always PILOT first.

5. **No audit logging** — Sending without context log. Safe_sendmail logs automatically.

6. **Attachment not readable** — Sending with broken/empty attachment. Test attachment before sending.

7. **Wrong email subject** — Generic or unclear subject line. Be specific (include position name).

8. **No CC verification** — Assuming CC is correct. Verify before sending.
