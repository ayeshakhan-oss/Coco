## Format Rules (LOCKED)

- **All emails:** Use [email_template_format_FINAL.md](../memory/email_template_format_FINAL.md) — Logo, blue header, blue horizontal line, justified Georgia text. NO asterisks in headings.
- **All PDFs:** Use ReportLab with TA_JUSTIFY on body text.
- **All interview invites:** Use [locked_email_template_interview_invites.md](../memory/locked_email_template_interview_invites.md) — #f3f4f6 bg, 620px card, 1.75 line-height.
- **CV screening reports:** Use [REPORT_FORMAT_LOCKED.md](../REPORT_FORMAT_LOCKED.md) — 4 stat boxes, Gmail-safe HTML table layout.
- **Decision briefs:** Hyperlink every candidate name to Google Drive CV.
- **Warm bench emails:** 800-1100 words MANDATORY. Haroon Yasin framework. Read [warm_bench_final_locked_approach.md](../memory/warm_bench_final_locked_approach.md) side-by-side before sending.

## Before You Start Any Task

1. **Read the relevant SOP** from the table above.
2. **Check memory/MEMORY.md** for past examples of this task type.
3. **Read the locked template** (if applicable).
4. **Read memory/lessons_learned.md** — Look for entries matching your task type. If this task has failed before, you'll see the mistake + rule.
5. **Create a draft** following the SOP exactly.
6. **Run self-QA checklist** (from CORE_DISCIPLINE.md) — All 8 items before sending.
7. **Send to Ayesha for approval** (never send to candidate directly without approval).

## Common Mistakes by Task Type

### CV Screening
- ✗ Fabricated candidate details not in CV
- ✗ Forgot to read locked template; generated wrong format
- ✗ Stat box count ≠ section header count
- ✓ Solution: Read REPORT_FORMAT_LOCKED.md + template memory first

### Rejection / Values / Warm Bench Emails
- ✗ Skipped locked template memory; deviated on format
- ✗ Word count too short (<800 words)
- ✗ Sent without pilot to Ayesha
- ✓ Solution: Print template side-by-side, run word count check, pilot first

### Attendance Reports
- ✗ Forgot template memory; generated with grid borders
- ✗ Wrong colors for section headers
- ✗ Stat count ≠ section count (fabricated data to fill gaps)
- ✓ Solution: Read attendance_report_complete_template.md FIRST. Use Teams + Markaz, no fabrication.

### Talent Sourcing
- ✗ Used only one search layer (Google only, no org pages or LinkedIn)
- ✗ Added unverified candidates to Markaz
- ✗ Skipped ground-truth verification
- ✓ Solution: Execute all 7 steps in sequence. Verify links before committing.
