THREE CORE LEAKAGE POINTS:
================================================================================

1. SCRIPTS RUN IN ISOLATION
   └─ send_job26_screening_report_final.py has hardcoded data
   └─ Zero imports from memory or SOP system
   └─ Ignores corrections even if memory updated

2. NO MEMORY INJECTION INTO GENERATION
   └─ Memory loads at session start (conversation context)
   └─ But task generation doesn't re-inject memory (foreground work)
   └─ Rules known but not applied when generating

3. NO ENFORCEMENT HOOKS
   └─ .claude/settings.local.json has permission rules
   └─ But no validation, pre-send checks, or format enforcement
   └─ Nothing prevents violations from being sent
