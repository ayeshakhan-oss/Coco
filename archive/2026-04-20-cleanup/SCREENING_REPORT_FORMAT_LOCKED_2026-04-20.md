## Critical Rules

1. **NO divs** — Tables only (Gmail strips divs)
2. **NO external CSS** — All inline `style=""` attributes
3. **NO special Unicode characters** — Use HTML entities:
   - `&mdash;` for em-dash (—)
   - `&middot;` for middle-dot (·)
   - `&amp;` for ampersand (&)
4. **NO font changes** — Georgia serif throughout
5. **NO color changes** — Exact hex values (#1a2a3a, #1565c0, etc.)
6. **NO layout changes** — Same structure, same spacing
